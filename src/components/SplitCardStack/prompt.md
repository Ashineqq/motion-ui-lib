# SplitCardStack — 卡片三阶段交互组件（最终实现规格）

使用 React + shadcn/ui + Tailwind CSS + framer-motion 实现的卡片交互组件。整体分为三个交互阶段，深色舞台背景、米白卡片、复古衬线标题，简约高级质感。纯前端动画，无后端接口。

## 通用规格

- **组件尺寸**：组件宽度默认 `100%`（页面主体）；卡片 4:3 宽高比，宽度默认 = 组件宽度的 50%（即屏幕宽度的一半），随容器宽度响应式变化（ResizeObserver 测量，可显式传入 `cardWidth` / `cardHeight` 覆盖）
- **卡片结构**：标题（必填）+ 正文（可选）+ 其他附加内容（可选，不传对应区域不渲染，留白）
  - 标题在卡片**左下角**（复古衬线，始终清晰）
  - 正文在**右下角**（右对齐）
  - 附加内容在卡片**上方**（无则空白）
- **视觉**：深色背景舞台（`#16131c` + 中央光晕）、米白卡片（`#f7f2e9`）、细边框、细微投影
- **内容清晰度规则**：仅标题始终清晰；正文与附加内容在非详情状态统一高斯模糊（`blur-[5px]` + 降透明度）

## 阶段1：初始散列布局（展开态）

- **Z 字形交错瀑布**：第 1 张在左、第 2 张在右、第 3 张在左……（奇偶交替）；每张依次下移（步进 = 卡高 × 0.65），前一张压住后一张上部约 35%，标题（左下角）全部露出
- 每张卡片带 ±3° 旋转与确定性伪随机抖动（正弦散列 `scatter`，相同 seed 恒定不跳动），营造纸张随意散落感；z-index 前面的卡在上
- **容器高度 = 散列卡片总高**（自动计算 `minHeight`），页面可上下滚动
- 点击任意卡片 → 进入阶段2

## 阶段2：点击收拢 + 定向抽入

点击任意卡片：
1. 所有卡片统一向画面中心收拢聚集（0.9s 平缓）
2. 被点击卡片**按归属队列方向抽离**：左队列的卡向左抽出、右队列的卡向右抽出；抽离最远点 `pullX = colX + 1.15 × 卡宽`，与其余卡片完全脱离（无重叠），可溢出到屏幕外
3. 抽入动画节奏：前段拉开（40% 时间）、后段归位（60%），全程连贯顺滑

## 阶段3：收拢堆叠详情浏览

- **只显示 4 张卡片**（环形窗口：从置顶卡起数 4 张，无论实际多少张；窗口外卡片隐藏），**堆叠完全居中**（水平 + 垂直）
- **姿态表**（角度由常量 `STACK_TILT = 5` 派生，一处可调）：
  | 位次 | 旋转 | 说明 |
  |---|---|---|
  | 位 1（顶层） | 0° | 摆正，内容全部清晰 |
  | 位 2 | +5° | 顺时针 |
  | 位 3 | +10° | 顺时针（依次递增） |
  | 位 4 | −5° | 向左（逆时针） |
- 各卡片静止尺寸相同（3/4 仅作为动画起点，非静止尺寸）
- **容器高度收拢到视口高度** → 页面不滚动，卡片堆居中；右侧固定竖向悬浮控制面板（圆形关闭 / 上一张 / 下一张按钮，不随卡片动画位移）
- **切下一页**：
  - 旧顶层抽出（保持原尺寸）→ 移向堆尾 → 移动全程持续缩小，**归位时缩到最小（尺寸归零）**
  - 原 2 号**直接归正**（平滑摆正到 0°），原 3、4 号角度过渡到新位次（左转 / 右转）
- **切上一页**：
  - 堆底卡（位 4）抽出上浮至顶层，移动过程**由小（3/4 大小）逐步放大恢复原尺寸**并摆正
  - 原 1、2 号右转，原 3 号左转，收尾顶层摆正
- 阶段3 内切换（上一张 / 下一张）**抽离方向统一从左侧**；动画时长 0.9s 平缓

## 关闭复位

- 点击关闭按钮：所有卡片扩散复位，回归 Z 字形散列布局（阶段1），恢复"仅标题清晰、正文与附加内容模糊"
- **页面立即定位到第三阶段顶层卡片在散列布局中的位置（视口居中）**——关闭瞬间即预计算目标滚动位置并平滑滚动，不再停留在页面顶部

## 开发约束与实现要点

1. 用 React 状态区分「初始分列堆叠模式 `spread`」「收拢单摞详情浏览模式 `stacked`」
2. 卡片数据结构：`SplitCard { id, title(必填), body?, extra? }`
3. 动画由 framer-motion 驱动；**动画触发用 `useAnimation` + `animateKey` 显式 `controls.start()`**——绕开 framer 对相同 keyframes target 的去重（`shallowCompare`），保证「切下一页 → 切上一页」这类往返切换也一定重放抽离/抽出动画
4. **ResizeObserver 只在容器宽度真正变化时才触发动画**——高度变化（收拢/展开）会逐帧触发 RO，若不拦截会导致卡片动画被反复重启、永远收不完
5. **容器高度不做 CSS 过渡**：避免关闭后 `scrollTo` 平滑滚动被内容高度逐帧变化打断；滚动定位用 `requestAnimationFrame` 等渲染完成后再执行
6. 容器滚动策略：展开态高度 = 散列总高（可滚动）；收拢态高度 = 视口高度（不滚动、卡片居中）
7. 确定性伪随机 `scatter(seed)`（正弦散列）保证散列布局重渲染不跳动
